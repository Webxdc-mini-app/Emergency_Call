# 非常ベル・早押しボタン

Delta Chatのグループで、ボタンを押した人と知らせたい内容を共有するwebxdcアプリです。非常ベル、集合の呼びかけ、受付の呼び出し、早押しクイズなどに使えます。

- アプリのバージョン：1.0.1
- README更新日：2026年10月18日

## 必要な環境

webxdcに対応したDelta Chatを使います。複数端末で共有する場合は、全員が同じグループに参加し、グループ内の**同じ添付アプリ**を開いてください。

## 使い始める

1. Delta Chatで、使いたいグループを開きます。
2. 代表者が `Emergency_Call_1.0.1.xdc` をグループへ送ります。
3. 全員が、その同じ添付を開いてアプリを起動します。
4. 練習であることを伝え、1回押して相手の履歴にも届くか確認します。

旧版や別々に送信した添付アプリとは履歴を共有しません。修正版を新しく送った場合、旧版の履歴は引き継がれません。

## 基本操作

1. 画面上部のメニューから、知らせたい内容を選びます。
2. 大きなボタンの説明を確認します。
3. 大きな **「押す！」** を1回押します。
4. 自分と相手の「押下履歴 • ランキング」に、名前と内容が表示されたか確認します。

メニューを選ぶだけでは送信されません。大きなボタンを押すたびに記録が追加されます。履歴は上下にスクロールして確認できます。

| メニュー | 使い方の例 | 伝える内容 |
| --- | --- | --- |
| 非常ベル | 緊急事態を知らせる | 非常事態発生 |
| 火災 | 火や煙を知らせる | 火災発生！避難してください |
| 救護要請 | けがや体調不良で助けを求める | 救護が必要です |
| 全員集合 | 集合を呼びかける | 全員集合してください |
| 早押しクイズ | 回答したいと知らせる | 早押し！ |
| 呼び出しベル | 受付などで相手を呼ぶ | 呼び出しがあります |

### 受信時の動作

アプリを開いていると、押した人と内容が一時表示され、履歴に追加されます。音・振動・OS通知は、端末とメッセンジャーの対応や設定に依存します。最初の画面操作がないと音が出ない場合があります。

上部の「押下した人」は、現在の履歴で押した人の数です。接続中の人数を表すものではありません。

### 履歴をリセットする

1. グループの相手へ、履歴を消すことを伝えます。
2. 右上の丸い矢印ボタンを押します。
3. 確認画面で「リセット」を押します。取り消す場合は「キャンセル」を押します。

**リセットは全員に共有されます。消した履歴を戻す機能はありません。** 反映までに端末間で時間差が生じる場合があります。

### 早押しクイズで使う

全員で「早押しクイズ」を選び、出題前に代表者が履歴をリセットします。全員の履歴が空になったことを確認してから出題し、回答したい人が1回押します。進行役が履歴を見て回答者を決めてください。

順位はアプリ内の共有順序です。通信の遅れや同時押しがあるため、実時間の厳密な先着順を保証しません。同じ人が複数回押すと、その回数だけ記録されます。

## 届かないとき

- 全員が、同じグループ内の同じ添付アプリを開いているか確認します。
- メニューを選んだ後、大きな「押す！」まで押したか確認します。
- Delta Chatでメッセージを送受信できる状態か確認し、しばらく待ちます。
- 送信失敗の表示が出た場合は、通信状態を確認してからもう一度試します。
- 音が出ない場合は、画面を一度操作し、音量・消音・通知設定を確認します。履歴が届いていれば押下情報は受信できています。

## 利用上の注意

- このアプリを押しても、消防・救急などへ自動通報されません。本当の緊急時は、周囲への声かけや必要な通報を優先してください。
- 通信はメッセージ配送に依存し、遅延することがあります。アプリを閉じている間の警報音も保証されません。
- 自分の履歴に記録されたことは、相手が内容を読んだという意味ではありません。反応がない場合は、通話など別の方法でも確認してください。
- 使用前に、実際に使う端末同士で送受信と通知を確認してください。

## 1.0.1の主な変更点

- `webxdc.js` の読み込みを追加し、通信APIが読み込まれない問題を修正。
- 6種類のメニューを2列×3行に変更。
- 通知用のメタデータを追加。
- 重複受信を排除し、受信順が異なる場合も共有履歴が一致するよう処理を変更。
- 起動時の履歴復元で、過去の押下の警報を鳴らさないよう変更。
- 音声処理に失敗しても送信を継続し、送信時の例外を表示。
- キーボードによるボタン押下に対応。

- [setUpdateListener](https://webxdc.org/docs/spec/setUpdateListener.html)
