はじめにと起動方法

このマニュアルは「非常ベル・早押しボタン」1.0.1の使い方を説明します。グループの相手へ、ボタンの種類と押した人の名前を知らせるアプリです。

まず覚える3つの操作

① メニューで内容を選ぶ → ② 大きな「押す！」を押す → ③ 相手の画面の履歴で届いたことを確かめる。

みんなで使い始める

  1. Delta Chatの、使いたいグループを開きます。
  2. 代表者が修正版「Emergency_Call_1.0.1.xdc」をグループへ送ります。
  3. 全員が、その同じ添付ファイルを開いてアプリを起動します。起動ボタンの表記は端末により異なります。
  4. 最初は練習であることを相手に伝え、1回押して双方の履歴に届くことを確かめます。

別々に添付し直したアプリや旧版では、同じ履歴を共有できません。全員がグループ内の同じ添付を開いてください。

緊急時に使う前に

このアプリを押しても、消防・救急などへ自動通報されません。本当の緊急時は、周囲への声かけや必要な通報を優先してください。配送の遅れや端末の通知設定により、すぐに相手へ伝わらない場合があります。

画面の見方

画面上部に6種類のメニューが2列で並びます。選んだメニューの色や、大きなボタンの説明が変わります。

図1　修正版の画面構成を示す説明図です。名前や履歴は例です。実際の見え方や絵文字は端末により異なります。

① メニューを押すだけでは送信されません。②「押す！」を押すと送信されます。③ 履歴は下へスクロールして確認できます。④ 右上の丸い矢印は、履歴を消すためのボタンです。

知らせる内容を選んで送る

6種類の使い分け

メニューこんなとき相手に示す内容
非常ベル緊急事態を知らせたい非常事態発生
火災火や煙を知らせたい火災発生！避難してください
救護要請けがや体調不良で助けが必要救護が必要です
全員集合グループ全員に集まってほしい全員集合してください
早押しクイズクイズで回答したい早押し！
呼び出しベル受付などで相手を呼びたい呼び出しがあります

送る手順

  1. 知らせたい内容のメニューを押します。選択したメニューが色付きになります。
  2. 大きなボタン上の説明を読み、内容が合っていることを確認します。
  3. 大きな「押す！」を1回押します。押すたびに履歴が増えます。
  4. 自分の履歴に名前と内容が表示されたことを確認します。相手にも、同じ履歴が届いたか確かめてもらいます。

相手が受け取ると

アプリを開いている相手の画面に、押した人と内容が一時表示され、履歴に追加されます。音・振動・端末の通知は、端末とアプリの対応や設定によって使えない場合があります。

ボタンを押したことは、相手が内容を読んだという意味ではありません。反応がないときは、通話など別の方法でも確認してください。

履歴の読み方

「押下履歴 • ランキング」には、押した人の名前、選んだメニュー、押した時刻などが並びます。「あなた」の印は自分の押下です。上部の「押下した人」は、現在の履歴で押した人の数であり、接続中の人数ではありません。

早押しクイズで使う

  1. 全員が同じ添付アプリを開き、「早押しクイズ」を選びます。
  2. 出題前に代表者が履歴をリセットし、全員の履歴が空になったことを確認します。
  3. 合図の後、答えたい人が「押す！」を1回押します。
  4. 履歴の順位を見て、進行役が回答する人を決めます。

順位はアプリ内で共有する順序です。通信の遅れや同時押しがあるため、実際に押した瞬間の厳密な先着順を保証しません。同じ人が何度も押すと、その回数だけ記録されます。

全員の履歴を消す

右上の丸い矢印を押すと、下図の確認画面が開きます。消す前にグループの相手に伝えてください。

図2　リセット確認画面の説明図。リセットすると、共有された全員の履歴が消えます。端末によって反映までに時間差が生じる場合があります。

困ったときと使用前の確認

相手に届かない

  1. 自分と相手が、同じグループ内の同じ添付アプリを開いているか確認します。旧版や別の添付を開いている場合は、同じ修正版を開き直します。
  2. メニューを選んだ後、大きな「押す！」まで押したか確認します。
  3. Delta Chatでメッセージを送受信できる状態か確認し、しばらく待ちます。
  4. 送信失敗の表示が出たら、状態を確認してからもう一度試します。緊急なら通話など別の手段で連絡します。

音や振動が出ない

最初にアプリの画面を一度操作してから試してください。端末の音量、消音設定、Delta Chatの通知設定も確認します。音や振動が出なくても、履歴が届いていれば押下情報は受信できています。アプリを閉じている間の警報音は保証されません。

メニューや履歴が見えない

修正版1.0.1を開いているか確認してください。6種類のメニューは2列×3行で並びます。履歴や画面下部は、上下にスクロールして確認します。

集まりや訓練の前に確認

  1. 全員が同じ添付アプリを開いている。
  2. 練習としてAからBへ、BからAへ、それぞれ1回押して履歴を確認した。
  3. 必要な端末で音・振動・通知を実際に試した。
  4. リセットすると全員の履歴が消えることを共有した。
  5. 届かない場合に使う連絡方法を決めた。
